# Spatial Hand Interface

## English

A gesture-controlled AR mini-game that turns your hands into the controller. Use your webcam to capture, stretch, rotate, and compress an energy core through four interactive stages.

Built with a minimalist monochrome design, the game features progressive challenge rounds and a camera-free simulation mode. All camera processing happens locally on your device—no video is uploaded.

### GitHub repository description

A webcam-powered AR mini-game. Capture, stretch, rotate, and compress an energy core with hand gestures. Built with MediaPipe and Canvas.

## 中文介绍

一款通过摄像头识别手势的 AR 互动小游戏。玩家用双手完成抓取、拉伸、旋转和压缩，操控屏幕中的能量核心。采用极简黑白视觉设计，支持多轮挑战，也提供无需摄像头的模拟模式。所有摄像头画面均在本机处理，不会上传。
